> 一个基于 **Xposed 框架** 的 **QQ / TIM 消息防撤回多功能模块**  

##  环境

| 项目       | 说明                                                |
|------------|-----------------------------------------------------|
| 适配客户端 | QQ / TIM Android（NT 架构）                         |
| 系统版本   | Android 8.1 ~ 17                                    |
| 框架支持   | LSPosed（默认）；也可通过 Zygisk 注入运行 |
